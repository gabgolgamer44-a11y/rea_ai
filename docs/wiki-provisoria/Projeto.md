# Sobre o projeto

REA significa **Reverse Engineer Anything**. O projeto upstream oferece fluxos de análise para ajudar agentes a investigar programas e apresentar resultados com evidências.

## Direção do REA AI

O rea_ai será uma continuação adaptada do [morluto/rea](https://github.com/morluto/rea). A intenção atual é incorporar o sistema completo e, em seguida, ampliar integrações com ferramentas de engenharia reversa.

O REA original já conecta agentes de IA. Recursos adicionais ou mudanças próprias de IA ainda serão especificados pelo proprietário; até lá, a integração existente deve ser preservada.
